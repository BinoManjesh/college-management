## A website for managing a college

### Directory structure:
- public - The public pages of the site
- src/inc - The common html contents to be reused
- src/libs - php scripts used by the public pages

### Overview
The College ERP (Enterprise Resource Planning) system is a comprehensive solution designed to streamline administrative workflows, enhance communication between stakeholders, and improve data management. This system provides role-based access to different users, ensuring smooth operations across departments. By digitizing and automating various academic and administrative processes, the ERP significantly increases operational efficiency and facilitates data-driven decision-making.

### Key Features

The ERP software is designed with customized interfaces for different user roles, ensuring accessibility and ease of use:

- Admin Interface

     - Full authority over the system.

     - Can add or remove courses, students, faculty members, and departments.

     - Can manage and oversee all activities within the ERP.

     - Can send important notifications to students and faculty members.

- Head of Department (HOD) Interface

     - Has all the functionalities available to faculty members.

     - Can oversee and manage departmental activities.

     - Can view and analyze student performance and faculty contributions.

- Faculty Interface

     - Can manage student attendance.

     - Can upload and update course materials.

     - Can assign and evaluate assignments.

     - Can enter student grades and provide feedback.

- Student Interface

     - Can view and download course materials.

     - Can submit assignments.

     - Can check attendance records and grades.

     - Can receive important notifications regarding courses and deadlines.
